# CRIME CITY GEORGIA — Godot 4 ეტაპი 1

ეს repository უკვე შეიცავდა ბრაუზერზე დაფუძნებულ Three.js დემოს. არსებული ვერსია შევინარჩუნე და ცალკე დავამატე Godot 4 პროექტი `godot/` საქაღალდეში.

## გაშვება კომპიუტერზე

1. დააინსტალირე Godot 4.3 ან უფრო ახალი ვერსია.
2. Godot Project Manager-ში აირჩიე **Import** და მიუთითე `godot/project.godot`.
3. დააჭირე **F6**-ს მიმდინარე სცენის ან **F5**-ს თამაშის გასაშვებად.

## ამ ეტაპზე მუშაობს

- მცირე პროცედურულად აგებული ქალაქის ქუჩები, შენობები და პარკი.
- მესამე პირის კამერით სიარული, სირბილი და ხტომა; კლავიატურაზე WASD/ისრები, Shift და Space.
- პატრულის მანქანაში ჩაჯდომა/გადმოსვლა და მართვა.
- მიწოდების შეკვეთის დაწყება/დასრულება და ₾250 урамаг்.
- ქართული HUD და ეკრэнზე მართვის ღილაკები.
- დღე-ღამის ციკლი.
- Лოკალური хадгалах: პოზიცია, мөнгө и დასრულებული მიწოდებების რაოდენობა `user://crime_city_georgia_save.json`-ში.
- Android-ზე გამოსაყენებლად Godot Compatibility renderer.

## Android APK ექსპორტი

Godot-ში დააყენე შესაბამისი Export Templates და Android-ისთვის საჭირო SDK/JDK, შემდეგ გახსენი **Project → Export**, დაამატე **Android** preset და დააყენე package name/signing პარამეტრები. ამ repository-ში ჯერ არ არის დამზადებული ან მოწყობილობაზე გამოცდილი APK; საბოლოო ექსპორტისთვის საჭიროა ეს ადგილობრივი Android გარემო.

## ცნობილი შეზღუდვები

ეს არის საწყისი, შესเล่นելի პროტოტიპი და არა AAA-ს მასშტაბის დასრულებული თამაში. ქალაქი შედგენილია მარტივი გენერირებული გეომეტრიით; ჯერ არ არის დეტალური ტექსტურები, პერსონაჟის ანიმაციები, პოლიციის AI, დანაშაულის/wanted სისტემა, ინტერიერები, ამინდი, სრული ინვენტარი, მაღაზიები, ბანკინგი, LOD ან მოწყობილობაზე FPS ტესტი. შემდეგ ეტაპებზე თითოეული სისტემა უნდა დაემატოს და შემოწმდეს.
